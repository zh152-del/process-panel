# 进程助手 · ProcessPanel

一款 Windows 桌面端的**实时进程内存监控面板**：按程序聚合全系统进程、按内存占用降序排行，悬停即可结束进程。

深色液态玻璃材质 + 鼠标追踪光效，可以常驻在桌面一角，不遮挡、不抢焦点。

---

## 功能特性

### 进程监控

- **按程序聚合**：同一程序的多进程合并为一行（如浏览器的多渲染进程、Electron 应用的多个子进程），显示 `×N` 进程数
- **内存降序排行**：每行显示排名、程序名、内存占用、占比条
- **前台优先**：前台窗口对应的进程优先展示，其余归入「后台」分类
- **自动刷新**：默认每 10 秒扫描一次，也可随时点击「扫描」立即刷新
- **结束进程**：每行右侧「结束」按钮，二次确认后执行；聚合行会结束该程序的全部进程
- **打开文件位置**：右键任意行，直接打开该程序所在目录

### 界面与交互

- 无边框圆角窗口，可自由拖动；支持锁定位置防误拖
- **三种材质主题**：液态玻璃 / 深色金属 / 白色玻璃，右键随时切换
- **材质透明度 5 档可调**（60% – 96%），实时生效并自动记忆
- **鼠标追踪光效**：内部柔光跟随鼠标移动，靠近哪条边哪条边亮，入场带扩散扫光
- 悬停微放大、聚合行扫光、状态色边框（前台绿 / 后台黄）
- **置顶显示**开关：勾选后常驻所有窗口之上

### 运行特性

- **单实例**：重复启动会点亮已有窗口，不会多开
- **配置持久化**：位置、材质、透明度、置顶状态保存在 exe 同目录的 `panel_layout.ini`
- **纯本地运行**：不联网、不上传任何数据、无遥测

## 安装

### 方式一：安装程序（推荐）

1. 到 [Releases](../../releases) 下载最新的 `进程助手-Setup-x.y.z.exe`
2. 双击运行，选择安装路径（默认 `C:\Program Files\ProcessPanel`）
3. 若系统缺少 .NET 8 桌面运行时，安装程序会提示并自动下载安装
4. 安装完成后从桌面或开始菜单启动

卸载：控制面板「应用」中卸载，或开始菜单「卸载进程助手」。

### 方式二：源码构建

```bash
git clone https://github.com/zh152-del/process-panel.git
cd process-panel
dotnet build -c Release
dotnet run -c Release
```

> 需要 .NET 8 SDK。

## 使用说明

| 操作 | 效果 |
|---|---|
| 左键拖动 | 移动面板 |
| 右键 | 菜单：置顶显示 / 切换材质 / 材质透明度 / 切换移动锁定 / 退出 |

| 点击「扫描」 | 立即刷新列表 |

## 技术实现

| 模块 | 方案 |
|---|---|
| UI 框架 | WPF（.NET 8，`net8.0-windows`），无第三方 UI 依赖 |
| 进程采集 | `System.Diagnostics.Process` 枚举进程，按可执行文件名聚合；友好名称取自文件版本信息 |
| 前台判定 | Win32 `GetForegroundWindow` + `GetWindowThreadProcessId` |
| 性能 | 扫描在后台线程完成，UI 线程只做差量更新；列表使用 `VirtualizingStackPanel` 虚拟化 |
| 材质 | `ResourceDictionary` 主题 + 多层渐变绘制；噪声纹理由 `WriteableBitmap` 程序化生成后冻结缓存 |
| 鼠标光效 | 自定义 `Adorner` 绘制层：环带几何（外圆角矩形 − 内圆角矩形）+ 以鼠标为圆心的径向渐变；移动时只更新渐变中心，不重建画刷与几何 |
| 窗口行为 | `AllowsTransparency` + `WindowStyle=None`，Win32 `SetWindowPos` 控制层级，`WS_EX_NOACTIVATE` 避免抢焦点 |

## 已知限制

- 仅支持 Windows x64
- 结束进程受权限限制：系统级或受保护进程需要管理员权限
- 内存取自进程工作集，与任务管理器的统计口径可能略有差异
- 未做代码签名，首次运行可能触发 SmartScreen「未知发布者」提示（选择「更多信息 → 仍要运行」）
